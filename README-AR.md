# MohammedLab PS5

هذه نسخة Windows x64 مبنية من مصدر KytyPS5 المثبّت والموضّح في
`build-manifest.txt`. فك ضغط الملف وشغّل `launcher.exe`. يتطلب المحاكي
تعريفًا متوافقًا مع Vulkan 1.3؛ ولا يوجد ضمان لتوافق كل الأجهزة.

المشغّل والمحاكي تجريبيان، وقد يختلف توافق الألعاب حسب اللعبة وإصدارها
وبطاقة الرسومات والتعريف. لا تتضمن الحزمة ألعابًا أو برنامج نظام PS5 أو
أدوات تطوير Sony أو مفاتيح. استخدم فقط بيانات ألعاب يحق لك استخدامها.

يمكن اختيار العربية أو الإنجليزية عند التشغيل الأول، أو تبديل اللغة فورًا
من القائمة مع حفظ الاختيار. تغطي الترجمة العربية المشغّل وبعض عناصر مكتبة
الألعاب؛ وتبقى بعض الإعدادات والنوافذ المتقدمة بالإنجليزية. يفحص تشخيص
الأجهزة محمّل Vulkan والأجهزة والميزات المحددة، لكنه لا ينشئ سطح عرض؛ لذلك
تبقى ملاءمة العرض والتقديم غير معروفة. يعرض البطاقات ولا يتيح اختيار محول
العرض. لا يثبت هذا الفحص توافق الألعاب ولا يثبّت التعريفات.

يعرض إعداد التشغيل الأول تقرير الأجهزة الحقيقي وإعداد مجلدات الألعاب وفحصها
في المشغّل الأصلي ثم اختبار SDL لوحدة التحكم بالتتابع، ويمكن تخطي كل خطوة.
يعرض اختبار SDL قيم المحاور والأزرار وحالة الاتصال الحية؛ لكنه لا يثبت عمل
الإدخال داخل اللعبة أو المحفزات التكيفية أو الاهتزاز. هذا الإعداد ليس معالج
توافق كاملًا.
